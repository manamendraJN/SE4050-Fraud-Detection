# Results

Saved outputs from model training and evaluation go here — one subfolder per model is recommended.

Example structure:
```
results/
  mlp/
    confusion_matrix.png
    roc_curve.png
    pr_curve.png
    metrics.csv
  cnn1d/
  lstm/
  tabnet/
  comparison/
    model_comparison_table.csv
    comparison_charts.png
```
